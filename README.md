# Subnet Calculator

An IPv4 subnet calculator that runs in the browser. Type an address with a prefix, such as 192.168.10.77/26, and get the answer instantly.

**Live app:** https://naveedakhtar-88.github.io/subnet-calculator/

## What it does

- Shows network address, broadcast address, subnet mask, wildcard mask, first and last usable host and the number of usable hosts.
- Shows a binary view so you can see exactly which bits belong to the network and which to the host.
- Splits a subnet into smaller subnets with a new prefix length and lists each one.
- Works fully offline after the page loads. Nothing is sent to any server.

## Tech

Plain HTML, CSS and JavaScript in a single file, hosted on GitHub Pages.
